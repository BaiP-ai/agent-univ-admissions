## How Reports are Generated

These reports are automatically generated through a GitHub Actions workflow that:

1. Scrapes data from university websites
2. Processes and structures the raw data
3. Enhances the structured data using AI (via the GROQ API)
4. Generates human-readable Markdown reports
5. Deploys the reports to GitHub Pages

## Custom Reports

If you'd like to generate a custom report for specific universities, you can:

1. Fork the [repository](https://github.com/BaiP-AI-Private/agent-univ-admissions)
2. Modify the university list in `config.py`
3. Run the generator with your preferred parameters
4. Submit a pull request with your changes
